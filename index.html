Concept overview

The Hessian decides what a critical point is

Let $f : \mathbb{R}^n \to \mathbb{R}$ be $C^2$ and $x_0 \in \mathbb{R}^n$. The gradient tells us where the surface is flat; the Hessian tells us how it bends there.

Critical Point & Extremum

$x_0$ is a critical point if $\nabla f(x_0) = 0$.

It is a local minimum if $f(x) \ge f(x_0)$ for all $x \in B_\epsilon(x_0)$, and a strict local minimum if $f(x) > f(x_0)$ for $x \ne x_0$ (p. 4); maxima reverse the inequalities.

A saddle point is a critical point that is neither.

Hessian Matrix $Hf(x)$ & Schwarz's Theorem (pp. 2–3)

$(Hf)_{ij}(x) := \dfrac{\partial^2 f(x)}{\partial x_i \, \partial x_j}$.

By Schwarz's Theorem (Lecture 16, p. 2), for $C^2$ functions $\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}$, so $Hf(x)$ is symmetric.

Definiteness & Eigenvalues

A symmetric $Hf$ has real eigenvalues and orthonormal eigenvectors.

Positive definite: $u^T Hf\, u > 0$ for all $u \ne 0$ (all $\lambda > 0$). Semi-definite: $\ge 0$ (all $\lambda \ge 0$). Indefinite: eigenvalues of both signs.

Theorem (Lecture 16, p. 6). Let $x_0$ be a critical point of $f$, i.e. $\nabla f(x_0) = 0$.
  1. If $x_0$ is a local minimum (maximum), then $Hf(x_0)$ is positive semi-definite (negative semi-definite).
  2. If $Hf(x_0)$ is positive definite (negative definite), then $x_0$ is a strict local minimum (maximum). If $Hf(x_0)$ is indefinite, then $x_0$ is a saddle point.

If $Hf(x_0)$ is only semi-definite (some $\lambda = 0$), the theorem is silent and higher-order terms decide (Mode 2).

All three functions have a critical point at the origin with the same Hessian $Hf(0,0) = \begin{bmatrix} 2 & 0 \\ 0 & 0 \end{bmatrix}$, which is positive semi-definite but not definite. Theorem (ii) does not apply, so the higher-order terms decide:

  • $f_1(x,y) = x^2 + y^4$: strict local minimum (the $y^4$ term curves up).
  • $f_2(x,y) = x^2 + y^3$: saddle point, neither a min nor a max (the $y^3$ term changes sign).
  • $f_3(x,y) = x^2$: local minimum that is not strict (flat along the $y$-axis).

Mode 2(b): Linear Least Squares

Lecture 16 (pp. 7–8): weight vector $w \in \mathbb{R}^n$, target $y$, design matrix $A$, and objective $$f(w) = \|y - Aw\|_2^2, \qquad \nabla f(w) = -2A^T(y - Aw).$$ Differentiating the gradient once more gives the constant Hessian $Hf(w) = 2A^TA$. Since $u^T(2A^TA)u = 2\|Au\|_2^2 \ge 0$, the Hessian is always positive semi-definite, so every critical point is a global minimum. It is positive definite (unique minimizer) exactly when $A$ has full column rank.

Team Explanation

Our demo explores how the Hessian matrix, defined entrywise as $(Hf)_{ij}(x) := \partial^2 f(x) / \partial x_i \partial x_j$, decides the nature of a critical point. Mode 1 uses the quadratic $f(x,y) = \tfrac12 ax^2 + bxy + \tfrac12 cy^2$. Its Hessian is the constant matrix with diagonal entries $a, c$ and off-diagonal entry $b$, so every slider change is an exact change to $Hf(0,0)$. The live math ribbon reports the trace, determinant, eigenvalues, eigenvectors, condition number, and a classification badge driven by the Lecture 16 theorem: positive definite gives a strict local minimum, negative definite a strict local maximum, indefinite a saddle, and a zero eigenvalue leaves the test inconclusive.

The angle slider $\theta$ picks a unit direction $u$. Plot C restricts $f$ to the line $tu$, reducing the $n$-dimensional question to the one-variable second-derivative test from page 5: $g'(0) = 0$ and $g''(0) = u^T Hf\, u$. Because $u^T Hf\, u = \lambda_1 (u \cdot v_1)^2 + \lambda_2 (u \cdot v_2)^2$, sweeping $\theta$ shows that every directional curvature lies between $\lambda_2$ and $\lambda_1$. The prediction prompt highlights the cross-term trap: with $a = c = 2$ both axes curve upward, yet once $b > 2$ the determinant turns negative and the surface bends down along the diagonal eigenvector $v_2$. Checking the diagonal entries alone is not enough.

Plot B overlays gradient descent and Newton's method. Gradient descent zig-zags when the condition number $\kappa$ is large, diverges when $\eta \lambda_{\max} > 2$, and near a saddle escapes along the negative-curvature eigenvector, especially with seeded noise switched on. Newton's method jumps to the critical point in one step whenever $Hf$ is invertible, even when that point is a saddle.

Mode 2 covers the cases the theorem cannot decide. The functions $x^2 + y^4$, $x^2 + y^3$, and $x^2$ share the Hessian $\mathrm{diag}(2, 0)$ at the origin, yet they give a strict minimum, a saddle, and a non-strict minimum. Finally, linear least squares $f(w) = \|y - Aw\|_2^2$ has $\nabla f(w) = -2A^T(y - Aw)$ and $Hf(w) = 2A^TA$, which is always positive semi-definite. Every critical point is therefore a global minimum, and it is unique exactly when $A$ has full column rank. Deep networks lose this structure, which is why their loss landscapes are full of saddle points.

Independent verification

  • verify_hessian.py (Python + NumPy) recomputes, for every preset and for 2,000 seeded random $(a, b, c)$: the eigenvalues and eigenvectors against numpy.linalg.eigh, a central finite-difference Hessian of $f$ against $\begin{bmatrix} a & b \\ b & c \end{bmatrix}$, the identity $u^T Hf\, u = \lambda_1 (u\cdot v_1)^2 + \lambda_2 (u \cdot v_2)^2$, the classification labels, the Newton step, and the GD stability threshold $\eta < 2/\lambda_{\max}$.
  • It also checks the prediction answer ($b = 2.5 \Rightarrow \lambda_2 = -0.5$, $v_2 = (-1/\sqrt2, 1/\sqrt2)^T$) and, for Mode 2(b), checks $\nabla f(w) = -2A^T(y - Aw)$ and $Hf(w) = 2A^TA$ against finite differences, and that $2A^TA \succeq 0$.
  • verify_mode2.py (Python + NumPy) independently verifies the Mode 2 calculations. For Mode 2(a), it checks that $f_1(x,y)=x^2+y^4$, $f_2(x,y)=x^2+y^3$, and $f_3(x,y)=x^2$ all have $Hf(0,0)=\begin{bmatrix}2 & 0 \\ 0 & 0\end{bmatrix}$, with eigenvalues $\lambda_1=2$ and $\lambda_2=0$, despite having different classifications (strict local minimum, saddle point, and non-strict local minimum). It also tests six column-similarity settings (0%, 25%, 50%, 75%, 95%, and 100%) and confirms that rank deficiency produces $\lambda_{\min}=0$. All mathematical checks passed.
  • In the browser we confirmed that the page loads from file:// with no console errors in either mode, that the Mode 1 readout matches verify_hessian.py for each preset, and that Mode 2(b) at 100% column similarity shows eigenvalues $96$ and $0$ for $m = 24$ observations (rank 1), matching verify_mode2.py.
